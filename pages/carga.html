2. Mapea tus columnas

Para cada columna, indica su papel: Dimensión si es una categoría por la que se puede agrupar la gráfica (municipio, padecimiento…), Medida si es un número que se debe sumar, Filtro si sirve para acotar la vista previa (año, institución, sexo…), o Ignorar. Los tres papeles son independientes entre sí — si marcas varias columnas como Dimensión o como Medida, en el siguiente paso eliges cuál usa la gráfica; si marcas varias como Filtro, todas aparecen a la vez y se combinan entre sí. Las columnas numéricas que se ven como año, semana, mes o clave se marcan "posible código" y no se proponen como Medida por defecto (puedes cambiarlo si hace falta).

Después puedes cambiar individualmente las columnas que necesites a Dimensión, Medida o Filtro.
